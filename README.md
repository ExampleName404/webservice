# Web Service

Работы по дисциплине **CSE5032 «Разработка веб-сервисов»** на ASP.NET Core Web API.

## Модуль 1. Основы ASP.NET Core Web API

Все три работы модуля (лабораторная, практическая и домашняя) выполнены в одном проекте.

| Работа | Репозиторий | Описание |
|---|---|---|
| Лабораторная, практическая работа и домашнее задание | [WebApiLab](https://github.com/ExampleName404/WebApiLab) | Students API (GET, POST) и Courses API (GET, POST, PUT, DELETE) |

## Модуль 2. Создание Web API

| Работа | Репозиторий | Описание |
|---|---|---|
| Лабораторная работа | [WB-LB-2](https://github.com/ExampleName404/WB-LB-2) | Tasks API: GET, POST, PUT, DELETE |
| Практическая работа | [WS-PR-2](https://github.com/ExampleName404/WS-PR-2) | Students API: получение и добавление студентов |
| Домашнее задание | [WS-HW-2](https://github.com/ExampleName404/WS-HW-2) | Books API: список книг и добавление книги |

## Модуль 3. Dependency Injection и логирование

| Работа | Репозиторий | Описание |
|---|---|---|
